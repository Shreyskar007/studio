# **App Name**: MeetFlow

## Core Features:

- Key Decision Extraction: Utilize AI to identify key decisions and discussion points in the meeting transcript to be used as a tool.
- Automated Action Item Detection: Extract and format action items and deadlines from meeting transcripts, and assign those tasks to individuals by leveraging AI tooling.
- Centralized Meeting Dashboard: Provide a clean, searchable interface for viewing meeting transcripts, action items, and key decisions.
- Automated Report Generation: Provide one-click exports for common file formats. 
- Data Security and Compliance: Securely store and manage meeting data, ensuring compliance and data protection.

## Style Guidelines:

- Primary color: A calm, confident blue (#4681C4), evoking trust and productivity.
- Background color: Light, desaturated blue (#EBF2FA), provides a clean and unobtrusive backdrop.
- Accent color: A muted green (#6B8E23), is used sparingly for highlights and key actions, signaling progress and decisions.
- Body and headline font: 'Inter', a sans-serif font that communicates a modern, machined and neutral look
- Use clear, minimalist icons to represent different meeting actions and statuses.
- Emphasize a clean, card-based layout to organize meeting information effectively.
